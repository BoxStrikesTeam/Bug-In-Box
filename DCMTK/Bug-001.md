# BOX-001 — DCMTK N-GET AttributeIdentifierList Memory Leak

**Researcher:** Eneshan Erdoğan Karaca  
**Team:** Boxstrike Security Research  
**Finding ID:** BOX-001  
**Date:** 2026-07-01  
**Status:** ✅ Confirmed — [OFFIS Redmine #1248](https://support.dcmtk.org/redmine/issues/1248)  
**Severity:** Medium (Remote DoS)  
**CVSS:** AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L

---

## Summary

A heap memory leak exists in DCMTK's DICOM network library. When a `DcmSCP`-based DICOM SCP receives an N-GET-RQ command with a non-empty `AttributeIdentifierList` (tag `0000,1005`), a buffer allocated via `malloc()` in `getAttributeList()` (`dcmnet/libsrc/dimcmd.cc:404`) is never freed. An unauthenticated remote attacker can exploit this by repeatedly sending N-GET-RQ messages to exhaust the SCP process memory.

## Call Chain

```
TCP connect()
  └─> negotiateAssociation()            [A-ASSOCIATE-RQ]
        └─> DIMSE_receiveCommand()      [dimse.cc:1234]
              └─> DIMSE_parseCmdObject()[dimcmd.cc:1866]
                    └─> parseNGetRQ()   [dimcmd.cc:1245]
                          └─> getAttributeList()
                                └─> malloc() ← [dimcmd.cc:404]  ALLOCATED
DcmSCP::receiveNGETRequest()            [scp.cc:1262]
  (buffer read, copied to OFList — NEVER FREED)              LEAKED
```

---

## Root Cause

```c
// dcmnet/libsrc/dimcmd.cc:403-404
if (*listCount > 0)
    *lst = (Uint16*)malloc((size_t)(nBytes + 1));  // allocated on heap

// dcmnet/libsrc/scp.cc — receiveNGETRequest()
T_DIMSE_N_GetRQ reqMessage;     // stack variable
DIMSE_receiveCommand(..., &reqMessage, ...);
// reqMessage.AttributeIdentifierList now points to heap buffer
// ...copied to OFList<DcmTagKey>...
return;
// stack frame gone, pointer lost, heap buffer NEVER freed
```

No `free()` call for `AttributeIdentifierList` exists anywhere in `dcmnet/`.

## Suggested Fix

```cpp
// dcmnet/libsrc/scp.cc — inside receiveNGETRequest()
if (reqMessage.AttributeIdentifierList != NULL) {
    free(reqMessage.AttributeIdentifierList);
    reqMessage.AttributeIdentifierList = NULL;
}
```
